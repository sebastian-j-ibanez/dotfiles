# Eiffel Retro

A light Omarchy theme based on the `eiffel_plain` Ghostty and Helix themes.
It uses Aether's Wallhaven integration for its included background and retains
the original's clean white surfaces, saturated green focus color, and retro
green/red/magenta accents. Accent shades were darkened where necessary to
keep ordinary desktop text readable.

Apply it with:

```bash
omarchy theme set eiffel-retro
```
